== What these prompts deliberately do not say

* No prompt proposes a single unified adapter, an Echo↔Resource conversion, or
  Echo-as-resource — all three are refuted in this estate.
* No prompt treats the map's "PROVEN (fragment)" as K-CUT resolved.
* No prompt asserts a mechanised dependency that does not exist. The only
  integration claim anywhere in this tree that lacks a CI import is the Lintel
  one, and prompt 11 opens by offering to withdraw it.
* No prompt claims GDPR, thermodynamic, cryptographic or side-channel
  properties. The non-claims list in `docs/secret-types.adoc` is load-bearing and
  travels with every handoff.
